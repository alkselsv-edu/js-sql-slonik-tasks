# Пул соединений

## solution.js

Реализуйте и экспортируйте по умолчанию асинхронную функцию. Функция принимает объект книги:

```js
{
  title: "Война и мир",
  author: "Лев Толстой",
}
```

Функция должна:

1. Создать пул Slonik с помощью `createPool()`.
2. Добавить книгу в существующую таблицу `books`.
3. Безопасно передать название и автора через параметры запроса.
4. Гарантированно закрыть пул, в том числе при ошибке.

Для подключения используйте `databaseUrl` из `database.js`.
