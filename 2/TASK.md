# Плейсхолдеры

## solution.js

Реализуйте и экспортируйте по умолчанию асинхронную функцию. Функция принимает массив объектов с данными статей:

```js
[
  { title: "Статья 1", description: "Описание статьи 1" },
  { title: "Статья 2", description: "Описание статьи 2" },
]
```

Функция должна:

1. Добавить все статьи в существующую таблицу `articles`.
2. Безопасно передать `title` и `description` через параметры Slonik.
3. Вернуть массив идентификаторов добавленных записей в том же порядке.
4. Закрыть пул соединений.

Для подключения используйте `databaseUrl` из `database.js`.

Пример:

```js
const ids = await solution(articles);
console.log(ids); // [1, 2]
```
