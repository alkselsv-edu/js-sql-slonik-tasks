# Транзакции

## solution.js

Реализуйте и экспортируйте по умолчанию асинхронную функцию бронирования номера:

```js
await solution(user, roomNumber, price);
```

Параметры:

- `user` — объект `{ username, phone }`;
- `roomNumber` — номер комнаты;
- `price` — цена бронирования.

В одной транзакции функция должна:

1. Добавить пользователя в таблицу `users`.
2. Найти свободную комнату по полю `room_number` и изменить её статус с `free` на `reserved`.
3. Добавить заказ в таблицу `orders`, используя идентификаторы пользователя и комнаты.

Если комнаты не существует, она уже забронирована или любой запрос завершается ошибкой, все изменения должны быть отменены, а функция должна выбросить ошибку.

Пул необходимо гарантированно закрыть после завершения функции. Для подключения используйте `databaseUrl` из `database.js`.
